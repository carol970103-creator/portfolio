課程簡介

本課程旨在建構大一新生對當代數位科技全貌的理解，包含硬體架構、軟體工程、網路通訊以及最新前沿科技（AI、雲端運算與資安概念），並結合網頁建置的實作專案。

重點學習單元

  • 計算機基礎： 邏輯閘、CPU 架構與記憶體管理機制。
  • 網頁前端發展： HTML5 語意化標籤、CSS3 佈局與 RWD 響應式設計。
  • 網頁網路原理： HTTP/HTTPS 協定、DNS 解析與 Web 伺服器運作概念。
  • 現代科技趨勢： 人工智慧應用（GenAI）、區塊鏈與資訊安全實務。

實作與成果

完成了個人作品集網頁的開發與部署，學習運用 Git 版控工具，並成功實作互動式前端介面設計。
